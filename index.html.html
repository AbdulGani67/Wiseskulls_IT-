05 — ROLE DEEP DIVE
Developers ✦
Roles & Responsibilities

Who Is a Developer?

The person who writes the actual code to build products — websites, apps, enterprise systems.

Key Responsibilities

  • Write, test, and debug code
  • Work with architects on design
  • Follow SDLC and Agile methodology
  • Collaborate with QA for testing
  • Deliver working features on time

Types of Developers

  • Frontend — React, Angular, SwiftUI
  • Backend — Java, Python, .NET, Node.js
  • Full Stack — both front & backend
  • Mobile — iOS, Android, Flutter
  • AI / ML — GenAI, RAG, Python
  • ERP — SAP, Oracle, Salesforce Apex

06 — ROLE DEEP DIVE
Testers / QA ⊙
Roles & Responsibilities

Who Is a Tester?

The person who ensures the product works correctly before it reaches the end user.

Key Responsibilities

  • Write test cases and test plans
  • Find bugs and raise defects in JIRA
  • Coordinate with developers to fix issues
  • Ensure product meets requirements
  • Work in CI/CD pipelines for automation

Types of QA / Testers

  • Manual QA — tests step by step, no code
  • Automation QA / SDET — writes test scripts
  • UAT Lead — user acceptance testing
  • Performance Tester — speed & load testing
  • QA Lead — manages full testing team

07 — ROLE DEEP DIVE
Leads ↗
Roles & Responsibilities

Who Is a Lead?

A senior developer or tester who leads a small team, reviews work, and bridges management and execution.

Key Responsibilities

  • Lead a team of 3–8 people
  • Code reviews and mentoring
  • Own technical decisions at team level
  • Report to architect or project manager
  • Handle client/stakeholder communication
💡 A DEVELOPER BUILDS. A LEAD BUILDS AND GUIDES OTHERS.

Types of Leads

  • Tech Lead / Dev Lead — code quality
  • QA Lead — test strategy & team
  • UI Lead — frontend team
  • Functional Lead — functional consultants

08 — ROLE DEEP DIVE
Architects ◈
Roles & Responsibilities

Who Is an Architect?

The person who designs the entire technical structure of a system — before a single line of code is written.

Key Responsibilities

  • Define technical blueprint for the project
  • Choose tools, platforms, integration patterns
  • Review developer work for alignment
  • Communicate with CTO & stakeholders
  • Own scalability, security, performance
💡 A LEAD MANAGES PEOPLE. AN ARCHITECT MANAGES THE BLUEPRINT.

Types of Architects

  • Solution Architect — end-to-end design
  • Technical Architect — tech & integrations
  • Enterprise Architect — org-wide design
  • Data Architect — data storage & flow
  • Cloud Architect — cloud infrastructure
  • GenAI Architect — AI-based systems ★

09 — ROLE DEEP DIVE
Consultants & Analysts ⊛
Roles & Responsibilities

Who Is a Consultant?

A specialist who configures, implements, or advises on a platform — bridging business and technology.

Key Responsibilities

  • Gather requirements from business users
  • Configure ERP/CRM/HCM platforms
  • Conduct CRPs, UAT & user training
  • Write BRDs, FRDs, functional specs
  • Link between business & technical teams

Types of Consultants / Analysts

  • Functional Consultant — configures, no coding
  • Technical Consultant — writes customisations
  • Techno-Functional — does both ★ most valuable
  • SME — deep product / domain expert
  • Business Analyst — bridges biz & IT

10 — ROLE DEEP DIVE
Managers / PMs ◎
Roles & Responsibilities

Who Is a Manager / PM?

The person who plans, organises, and drives project delivery — owning timelines, budget, risks, and stakeholder communication.

Key Responsibilities

  • Define project scope & timeline
  • Manage risks, issues, dependencies
  • Communicate with clients & leadership
  • Track KPIs and delivery metrics
  • Lead cross-functional teams
💡 A LEAD OWNS CODE QUALITY. A PM OWNS DELIVERY.

Types of Managers / PMs

  • Project Manager — owns one specific project
  • Program Manager — oversees multiple projects
  • Agile PM / Scrum Master — Agile ceremonies
  • TPM — technical depth + PM skills
  • Product Manager — owns product roadmap
